Property Ledger

A Windows desktop app for rental-property record preparation.

Available from Microsoft Store

Property Ledger is a Windows desktop app published by MACCA CONSULTING PTY LTD for rental-property record preparation.

The app helps rental-property owners organise rental statements, invoices, notices, CSV files and Excel rows into a reviewable draft ledger. It supports source-document review, monthly rental income and expense summaries, review cues, and CSV export workflows.

Property Ledger is a working-paper tool. It is not tax advice and does not lodge tax returns. Users should review source documents, categories, totals and exported files before relying on them or giving them to an accountant.

Features

Practical tools for rental-property records

  • Source-document review
    Review rental statements, invoices and notices alongside captured ledger rows so source records remain visible during checking.
  • Monthly rental summaries
    Prepare monthly rental income and expense summaries that can be reviewed before use in later bookkeeping or accountant workflows.
  • Review cues
    Use review cues to identify entries that need checking, categorisation, adjustment, or source-document confirmation.
  • Spreadsheet import
    Bring CSV files and Excel rows into the working ledger where supported, then review the imported rows before relying on them.
  • CSV export workflows
    Export reviewed ledger data to CSV for further checking, storage, or hand-off to another workflow.

How It Works

A review-first desktop workflow

  1. Add source records
    Select rental statements, invoices, notices, CSV files or Excel rows from your working folder.
  2. Build a draft ledger
    Use the imported and captured rows to prepare draft ledger working papers for the property.
  3. Review the evidence
    Check source documents, categories, totals and review cues before relying on the data.
  4. Prepare monthly summaries
    Review monthly rental income and expense summaries as part of your working-paper file.
  5. Export CSV files
    Use CSV export workflows to move reviewed ledger data into another recordkeeping process where appropriate.
